# TA3NA — le sondage

La page que les potes de Samer remplissent pour donner leurs mots au jeu TA3NA.
Servie par GitHub Pages ; les réponses partent par WhatsApp, rien n'est enregistré ici.

`index.html` est FABRIQUÉE : on modifie `modele.html`, puis `python3 fabriquer.py`
(qui y met l'icône de l'app, depuis le dépôt `ta3na-source`, rangé à côté).
